# Trim a gps object based on provided trimming quantiles

Trims a gps object based on provided trimming quantiles.

## Usage

``` r
trim_gps(gps_obj, trim_quantiles)
```

## Arguments

- gps_obj:

  A gps S3 object.

- trim_quantiles:

  A vector of trimming quantiles with two min and max values.

## Value

A trimmed gps_obj
