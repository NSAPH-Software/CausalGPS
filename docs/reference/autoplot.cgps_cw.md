# A helper function for cgps_cw object

A helper function to plot cgps_cw object using ggplot2 package.

## Usage

``` r
# S3 method for class 'cgps_cw'
autoplot(object, ...)
```

## Arguments

- object:

  A cgps_cw object.

- ...:

  Additional arguments passed to customize the plot.

## Value

Returns a ggplot object.
