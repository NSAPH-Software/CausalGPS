# A helper function for gpsm_erf object

A helper function to plot gpsm_erf object using ggplot2 package.

## Usage

``` r
# S3 method for gpsm_erf
autoplot(object, ...)
```

## Arguments

- object:

  A gpsm_erf object.

- ...:

  Additional arguments passed to customize the plot.

## Value

Returns a ggplot object.
